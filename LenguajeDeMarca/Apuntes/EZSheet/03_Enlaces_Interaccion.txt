2.2. Enlaces e interacción

• :link: enlace no visitado.
• :visited: enlace ya visitado.
• :hover: cuando el ratón está encima.
• :active: mientras se está haciendo clic.
• :focus: elemento con foco (clic o teclado).
• :focus-visible: foco visible sólo cuando viene del teclado (mejora accesibilidad).
• :focus-within: se aplica a un contenedor si algún descendiente tiene foco.
• :any-link: cualquier enlace con href (a o area).

Ejemplo:
css
a:link { color: blue; }
a:visited { color: purple; }
a:hover { text-decoration: underline; }
a:active { color: red; }
