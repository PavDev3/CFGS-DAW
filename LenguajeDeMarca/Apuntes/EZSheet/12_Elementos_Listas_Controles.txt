3.5. Listas y controles especiales

• ::marker: marcador de listas (ul / ol), viñetas o números.
• ::file-selector-button: botón de los inputs type="file".

Ejemplos:
css
li::marker {
color: #f39c12;
font-size: 1.2em;
}
input[type="file"]::file-selector-button {
background: #3498db;
color: white;
border: none;
padding: 0.4em 0.8em;
border-radius: 4px;
cursor: pointer;
}
