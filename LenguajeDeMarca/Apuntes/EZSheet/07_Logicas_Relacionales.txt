2.6. Pseudo-clases lógicas y relacionales

• :not(selector): selecciona elementos que NO coinciden con el selector.
• :is(selector-list): agrupa varios selectores, simplificando el código.
• :where(selector-list): como :is, pero con especificidad 0 (ideal para estilos base).
• :has(selector): "mira hacia abajo"; selecciona un elemento si contiene algo que coincide con el selector.

Ejemplo con :has:
css
.card:has(input:invalid) {
border-color: red;
}
