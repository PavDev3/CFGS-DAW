3.4. Formularios y selección de texto

• ::placeholder: estilo del texto placeholder de inputs y textareas.
• ::selection: estilo del texto seleccionado por el usuario (color de fondo / texto).

Ejemplo:
css
::selection {
background: #b3b3b3;
color: #000;
}
input::placeholder {
color: #aaa;
font-style: italic;
}
