# 2.2. Utilización de los distintos tipos de variables y operadores disponibles en el lenguaje

## Declaración de variables

JavaScript ofrece tres formas de declarar variables:

```javascript
var nombre = "Pablo";   // ámbito de función, puede redeclararse (forma antigua, evitar)
let edad = 20;           // ámbito de bloque, se puede reasignar
const PI = 3.1416;       // ámbito de bloque, no se puede reasignar
```

- `var` tiene ámbito de función y permite redeclarar la misma variable, lo que puede causar errores difíciles de detectar. Hoy en día se evita su uso.
- `let` tiene ámbito de bloque (`{ }`) y se usa cuando el valor de la variable va a cambiar.
- `const` también tiene ámbito de bloque, pero no permite reasignar el valor una vez declarado. Se usa para valores que no deben cambiar.

## Tipos de datos

JavaScript es un lenguaje de **tipado dinámico**: el tipo de una variable se decide según el valor que contiene, y puede cambiar.

| Tipo | Ejemplo |
|------|---------|
| `number` | `let precio = 19.99;` |
| `string` | `let texto = "Hola mundo";` |
| `boolean` | `let activo = true;` |
| `undefined` | `let x;` (declarada pero sin valor) |
| `null` | `let y = null;` (vacío de forma intencionada) |
| `object` | `let persona = { nombre: "Ana", edad: 25 };` |
| `array` (tipo especial de objeto) | `let colores = ["rojo", "verde", "azul"];` |

Se puede comprobar el tipo de una variable con el operador `typeof`:

```javascript
console.log(typeof precio);   // "number"
console.log(typeof texto);    // "string"
```

## Operadores

### Aritméticos
```javascript
let suma = 5 + 3;        // 8
let resta = 5 - 3;       // 2
let multiplicacion = 5 * 3; // 15
let division = 5 / 3;    // 1.666...
let resto = 5 % 3;       // 2 (módulo)
let potencia = 5 ** 2;   // 25
```

### De asignación
```javascript
let contador = 0;
contador += 1;   // equivale a contador = contador + 1
contador -= 1;
contador *= 2;
```

### De comparación
```javascript
5 == "5"    // true  (compara solo el valor, convirtiendo tipos)
5 === "5"   // false (compara valor y tipo, sin conversión)
5 != 3      // true
5 !== "5"   // true
5 > 3       // true
5 <= 5      // true
```

Es recomendable usar siempre `===` y `!==` en vez de `==` y `!=`, para evitar errores por conversiones de tipo inesperadas.

### Lógicos
```javascript
true && false   // AND -> false
true || false   // OR  -> true
!true           // NOT -> false
```

## Conclusión

JavaScript permite declarar variables con `var`, `let` y `const`, siendo `let` y `const` las formas recomendadas hoy en día. Al ser de tipado dinámico, una misma variable puede almacenar distintos tipos de datos (números, cadenas, booleanos, objetos, etc.) a lo largo de su vida. Los operadores aritméticos, de asignación, de comparación y lógicos permiten realizar cálculos y tomar decisiones dentro del código, siendo buena práctica usar siempre los operadores de comparación estrictos (`===`, `!==`) para evitar errores de conversión de tipos.
