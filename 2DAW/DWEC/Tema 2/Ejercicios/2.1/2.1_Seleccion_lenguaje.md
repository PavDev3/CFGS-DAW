# 2.1. Selección de un lenguaje de programación de clientes Web

Para la programación en el lado del cliente, el lenguaje elegido es **JavaScript**. A continuación se justifica esta elección frente a otras alternativas existentes.

## Alternativas consideradas

- **JavaScript**: es el único lenguaje que todos los navegadores interpretan de forma nativa, sin necesidad de plugins ni pasos previos de compilación para poder ejecutarse.
- **TypeScript**: es un superconjunto de JavaScript que añade tipado estático. Mejora la detección de errores en proyectos grandes, pero necesita un paso de compilación (transpilación) a JavaScript antes de poder ejecutarse en el navegador.
- **WebAssembly (Wasm)**: permite ejecutar código compilado desde otros lenguajes (C, C++, Rust) a gran velocidad, pero no sustituye a JavaScript para la manipulación del DOM ni para la interacción habitual con la página; se usa más bien como complemento para tareas muy exigentes (cálculo, gráficos, etc.).
- **Dart (con Flutter Web)**: permite compilar a JavaScript o Wasm, pero su uso está más extendido en aplicaciones móviles que en desarrollo web de propósito general.

## Motivos de la elección

1. **Soporte nativo en el navegador**: JavaScript se ejecuta directamente, sin instalar nada adicional ni compilar previamente.
2. **Comunidad y documentación**: es el lenguaje de programación web con más documentación, foros y recursos de aprendizaje disponibles.
3. **Integración con HTML y CSS**: fue diseñado específicamente para interactuar con el DOM, gestionar eventos y modificar el contenido y estilo de una página en tiempo real.
4. **Ecosistema de herramientas**: cuenta con gestores de paquetes (npm), frameworks (React, Vue, Angular) y herramientas de desarrollo muy maduras.
5. **Curva de aprendizaje**: su sintaxis es asequible para quien empieza, y permite escribir desde pequeños scripts hasta aplicaciones complejas.

## Conclusión

JavaScript es la opción más adecuada para la programación de clientes web porque es el único lenguaje soportado de forma universal por los navegadores, cuenta con el ecosistema más grande de herramientas y documentación, y se integra de forma natural con HTML y CSS. Otras alternativas como TypeScript pueden usarse como una capa adicional sobre JavaScript en proyectos más grandes, pero no lo sustituyen como lenguaje base de ejecución en el navegador.
