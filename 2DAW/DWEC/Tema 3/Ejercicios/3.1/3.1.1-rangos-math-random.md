# Actividad 3.1.1. Descifra los Rangos de Math.random()

El enunciado dice "5 funciones" pero el bloque de código trae 8 (`funcionA`-`funcionE`, `numeroA`, `numeroB`, `F`). Analizo las 8 por si acaso; las 5 principales parecen ser `funcionA`-`funcionE`.

| Función | Rango exacto [min, max] | Decimales |
|---|---|---|
| `funcionA` | [10, 20] | 0 (entero) |
| `funcionB` | [0, 1] | 1 |
| `funcionC` | [5, 15] | 2 |
| `funcionD` | [1, 6] | 0 (entero) — tirada de dado |
| `funcionE` | [-1, 1] | 3 |
| `numeroA` | [0, 100] | 0 (entero) |
| `numeroB` | [0, 1] | 0 (entero) — cara o cruz |
| `F` | [0, 1] | Sin fijar — no usa `toFixed`, devuelve el flotante completo (simula `Math.random()` a mano con un entero grande) |

## Razonamiento (ejemplo con `funcionC`, el más largo)

```js
function funcionC() {
  const minEscalado = 500;
  const maxEscalado = 1500;
  const enteroBase = Math.floor(Math.random() * (maxEscalado - minEscalado + 1)) + minEscalado;
  return Number((enteroBase / 100).toFixed(2));
}
```

1. `maxEscalado - minEscalado + 1 = 1001` → `Math.random() * 1001` da un decimal en `[0, 1001)`.
2. `Math.floor(...)` lo convierte en un entero `[0, 1000]`.
3. `+ minEscalado` lo desplaza a `[500, 1500]`.
4. `/ 100` lo reduce a `[5.00, 15.00]`.
5. `toFixed(2)` fija 2 decimales como string, `Number(...)` lo vuelve a convertir a número.

El patrón general para los rangos escalados (`funcionA`, `funcionC`, `funcionE`) es siempre:
`Math.floor(Math.random() * (max - min + 1)) + min`, que da un entero en `[min, max]` ambos inclusive — luego se divide y se redondea según cada caso.
