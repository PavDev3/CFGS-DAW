## Componentes de un Sistema Informático

Un sistema informático está formado por:
- **Hardware:** Componentes físicos (CPU, RAM, almacenamiento, periféricos)
- **Software:** Programas y sistemas operativos
- **Firmware:** Software integrado en hardware (BIOS/UEFI)
- **Usuarios:** Personas que interactúan con el sistema

---

## La BIOS/UEFI

### Menús de la BIOS

| Menú | Contenido |
|------|-----------|
| **MAIN** | Configuración básica: procesador, fecha/hora, memoria total, número de serie |
| **ADVANCED** | Configuración técnica: CPU, ACPI, PCIExpress, USBs |
| **BOOT** | Orden de arranque del sistema |
| **SECURITY** | Contraseñas de discos, BIOS, administración y TPM |
| **EXIT** | Guardar cambios o salir sin guardar |

---

## Máquinas Virtuales

Una **máquina virtual (VM)** es una emulación de un sistema informático real.

### Ventajas de las máquinas virtuales
- Aislamiento del sistema host
- Snapshots (puntos de restauración)
- Fácil clonación y migración
- Múltiples sistemas operativos en un solo hardware

### Hipervisores
| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Tipo 1 (Bare Metal)** | Se instala directamente en el hardware | VMware ESXi, Hyper-V |
| **Tipo 2 (Hosted)** | Se instala sobre un SO host | VirtualBox, VMware Workstation |
