## Sistemas Operativos

Un **sistema operativo (SO)** es el software principal que gestiona el hardware y proporciona servicios a las aplicaciones.

### Funciones del SO
- Gestión de procesos
- Gestión de memoria
- Gestión de almacenamiento
- Gestión de dispositivos de E/S
- Interfaz con el usuario

### Tipos de SO más usados en clase

| SO | Tipo | Uso principal |
|----|------|---------------|
| Windows 10/11 | Propietario | Escritorio empresarial |
| Ubuntu Linux | Libre | Servidores y desarrollo |
| macOS | Propietario | Desarrollo y diseño |

## Instalación en VirtualBox

### Recomendaciones de recursos por VM

| VM | CPU | RAM | Disco |
|----|-----|-----|-------|
| Ubuntu | 2 CPU | 2-4 GB | 20 GB |
| Windows | 2 CPU | 4-8 GB | 40 GB |

### Pasos para crear una VM en VirtualBox

1. Abrir VirtualBox
2. Clic en "Nueva"
3. Configurar nombre, tipo y versión del SO
4. Asignar RAM
5. Crear disco duro virtual (VDI, dinámico o tamaño fijo)
6. Adjuntar ISO en Configuración → Almacenamiento
7. Iniciar la VM y seguir el instalador
