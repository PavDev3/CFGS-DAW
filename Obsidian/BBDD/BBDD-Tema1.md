## ¿Qué es una Base de Datos?

Una **base de datos** es una colección organizada de información estructurada que:
- Almacena datos de forma ordenada
- Proporciona estructura a los datos
- Ofrece operaciones CRUD (Create, Read, Update, Delete)

---

## Funciones del SGBD (Sistema Gestor de Bases de Datos)

- CRUD (operaciones básicas)
- Seguridad y control de acceso
- Backup y recuperación

---

## Roles en una Base de Datos

| Rol | Descripción |
|-----|-------------|
| **Programadores** | Diseñan los programas que usan la BD |
| **Administradores de BD (DBA)** | Gestionan la base de datos |
| **Usuarios finales** | Interactúan con la BD |

---

## Tipos de Bases de Datos

| Tipo | Descripción |
|------|-------------|
| **Jerárquica** | Estructura solo de padre a hijos |
| **En Red** | Estructura que cruzan padres e hijos |
| **Orientada a Objetos (OOP)** | BD como colección de objetos |
| **Relacional** | Tablas relacionadas entre sí de forma lógica |
| **Entidad-Relación** | Relaciones entre entidades al estilo Red |
| **No relacionales (NoSQL)** | Estructura en bloque, como JSON |

---

## Conceptos Clave

- **Primary Key (PK):** Columna especial designada de manera única. Debe tener valor único y nunca NULL.
- **Foreign Key (FK):** Columna para asignar relaciones entre tablas.

---

## Bases de Datos No Relacionales (NoSQL)

Estructura de base de datos en bloque, como un JSON. Ejemplos: MongoDB, Cassandra, Hadoop.
