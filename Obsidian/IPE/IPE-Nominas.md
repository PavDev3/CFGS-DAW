## Fórmulas Oficiales

```
BCCC = Devengos cotizables + Prorrata PE - Devengos no cotizables
       (NO incluye Horas Extraordinarias)

BCCP = BCCC + Horas Extraordinarias

BHE  = Horas Extraordinarias

BASE IRPF = BCCC SIN la prorrata de las Pagas Extraordinarias

DEDUCCIONES = %Trabajador + Deducción HE + Deducción IRPF

LÍQUIDO = Salario Bruto - Deducciones
```

## Puntos clave para no confundirse

1. **IRPF** se calcula sobre la **BASE IRPF (SIN prorrata de pagas extras)**
2. **AT/EP** siempre se incluye en las deducciones del trabajador
3. **BCCC** incluye la prorrata de pagas extras
4. **Contrato temporal** → tipo de desempleo 1,60% (no 1,55%)
5. **Contrato indefinido** → tipo de desempleo 1,55%
