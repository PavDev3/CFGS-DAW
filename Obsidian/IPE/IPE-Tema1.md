## El Sector de las TIC

El módulo de IPE estudia la inserción laboral en el sector de las Tecnologías de la Información y la Comunicación (TIC).

### Perfil del Técnico Superior en DAW

El **Técnico Superior en Desarrollo de Aplicaciones Web** trabaja en:
- Desarrollo de aplicaciones web en el lado del cliente
- Desarrollo de aplicaciones web en el lado del servidor
- Implementación, verificación y documentación de aplicaciones web

### Salidas profesionales

| Puesto | Descripción |
|--------|-------------|
| Desarrollador/a web front-end | HTML, CSS, JavaScript |
| Desarrollador/a web back-end | PHP, Java, Node.js |
| Desarrollador/a full-stack | Front-end + back-end |
| Analista/programador | Análisis y codificación |
