## Algoritmos

Un **algoritmo** es una secuencia finita de instrucciones bien definidas que resuelve un problema.

### Características
- **Finito:** Tiene un número determinado de pasos
- **Definido:** Cada paso está claramente especificado
- **Efectivo:** Cada paso puede ejecutarse en tiempo finito

---

## Diagramas de Flujo

Los **diagramas de flujo** representan gráficamente un algoritmo.

### Símbolos principales

| Símbolo | Significado |
|---------|-------------|
| Óvalo | Inicio / Fin |
| Rectángulo | Proceso / Instrucción |
| Rombo | Decisión (condición) |
| Paralelogramo | Entrada / Salida |
| Flecha | Flujo de control |

---

## Estructuras de Control

### Secuencia
Instrucciones que se ejecutan una tras otra en orden.

### Selección (Decisión)
```
SI condición ENTONCES
    acción_verdadera
SINO
    acción_falsa
FIN SI
```

### Iteración (Bucles)

**Bucle MIENTRAS:**
```
MIENTRAS condición
    instrucciones
FIN MIENTRAS
```

**Bucle PARA:**
```
PARA i = inicio HASTA fin CON PASO p
    instrucciones
FIN PARA
```
