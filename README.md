# Grado Superior DAW — Materiales por curso y asignatura

Repositorio para centralizar recursos, ejercicios y apuntes del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW). El contenido está organizado **por curso** y, dentro de cada curso, **por asignatura**.

## Estado
En desarrollo continuo: se añaden prácticas, apuntes y proyectos regularmente.

## Estructura del proyecto

```
1DAW/                 Primer curso
├── BBDD/
├── Ciberseguridad/
├── Digitalizacion/
├── ENDES/
├── Examen BBDD/
├── IPE/
├── Java/
├── LenguajeDeMarca/
├── Programacion/
├── ProyectoFinalGrado/
├── Sistemas/
├── Sostenibilidad/
└── informe/

2DAW/                 Segundo curso (en construcción)

Obsidian/             Bóveda de apuntes (por asignatura)
```

- **1DAW/** — todo el material del primer curso.
- **2DAW/** — se irá llenando durante el segundo curso.
- **Obsidian/** — apuntes en Markdown; se mantiene en la raíz como bóveda.

## Cómo usar
- Entra en el curso (`1DAW/` o `2DAW/`) y luego en la asignatura.
- Abre los archivos con tu editor preferido.
- Para front-end, abre `index.html` o las demos locales; para proyectos de servidor, sigue las instrucciones de cada carpeta.

## Contribuir
- Abre un issue para propuestas o problemas.
- Envía pull requests con:
    - Descripción clara del cambio.
    - Archivos organizados según la estructura (curso → asignatura).
    - Separar soluciones en `soluciones/` o ramas distintas si procede.
- Mantén nombres de carpetas claros y consistentes.
